# ♞ Шахматы · Живая Арена

Браузерные шахматы, в которых **поле живёт своей жизнью**. Под капотом настоящие шахматы со всеми правилами, а сверху арена 10×10 с клетками силы и мировыми событиями.

> Azyon Incubator 2026, второй тур: «Шахматы». Игра сделана с помощью ИИ (Claude Code).

## Своя фишка: «Живая Арена»

### 🗺️ Поле 10×10
Обычная армия стоит по центру, по краям остаются открытые фланги. Пешки превращаются на 10-й горизонтали. Рокировка, взятие на проходе и превращение работают как в классике.

### ✦ Клетки силы (личные события)
Фигура, вставшая на клетку, получает эффект. Король клетки не активирует.

| | Клетка | Эффект |
|---|---|---|
| ⚡ | Рывок | Фигура сразу делает ещё один ход (без взятия) |
| 🛡️ | Щит | Фигуру нельзя взять 3 хода соперника; спасает и от метеорита |
| ❄️ | Капкан | Фигура вмерзает на 2 своих хода, но продолжает бить |
| 🌀 | Портал | Перенос на парный портал, если тот свободен |
| 👁️ | Око | Следующий туман войны вам не страшен |
| ⭐ | Академия | Пешка превращается в коня или слона |

### 🌍 Мировые события (общие)
Каждые несколько ходов арена объявляет событие, **всегда за 4 хода до начала**, чтобы игроки успели подготовиться.

| | Событие | Что происходит |
|---|---|---|
| 🌫️ | Туман войны | Видно только клетки рядом со своими фигурами. При игре вдвоём между ходами появляется экран «передайте устройство» |
| 🌙 | Ночь | Ладьи, слоны и ферзи ходят и бьют не дальше 3 клеток |
| ☄️ | Метеоритный дождь | Метеориты уничтожают фигуры на отмеченных клетках и оставляют кратеры, через которые нельзя пройти |
| ✨ | Дождь рун | На поле появляются новые клетки силы |

### ⚖️ Честность
- Всё случайное выбирается заранее, в момент объявления. Игроки и бот видят, что произойдёт.
- Шах, мат и пат учитывают все эффекты. Нельзя сделать ход, после которого с наступлением события ваш король окажется под боем.
- Метеориты не трогают королей. Клетки силы появляются симметрично.
- Есть режим **«Классика 8×8»**: чистые шахматы без событий.

## Что есть в игре
- ✅ Все правила: рокировка, взятие на проходе, превращение пешки, шах, мат, пат, троекратное повторение, правило 50 ходов, недостаточный материал.
- ✅ Игра вдвоём на одном устройстве, индикатор хода, кнопка «Новая игра».
- ✅ Бот с тремя уровнями (альфа-бета поиск в Web Worker). Он понимает все события арены и уводит фигуры от метеоритов.
- ✅ Подсветка доступных ходов, последнего хода и шаха; перетаскивание и клик.
- ✅ История ходов в фигурной нотации, отмена хода, переворот доски.
- ✅ Таймер (5 / 10 / 15 минут).
- ✅ Адаптивная вёрстка под телефон, звуки на WebAudio.

## Запуск локально
Проект статический, сборка не нужна. Из-за ES-модулей нужен любой локальный сервер:

```bash
python -m http.server 8080
```

Затем откройте http://localhost:8080.

## Тесты движка
```bash
node tests/run.mjs
```
Perft на эталонных позициях (стартовая, Kiwipete и др.) подтверждает корректность генерации ходов, включая рокировку, взятие на проходе и превращения. Ещё есть сценарии для каждой клетки и события арены и 30 случайных партий.

## Структура
```
index.html        разметка и диалоги
css/style.css     оформление, анимации, адаптив
js/engine.js      правила, клетки силы, события, нотация, perft
js/ai.js          бот (альфа-бета + форсированные взятия)
js/ai-worker.js   запуск бота в отдельном потоке
js/main.js        интерфейс: доска, ввод, эффекты, таймер
js/sound.js       синтез звуков
tests/run.mjs     тесты движка
```
