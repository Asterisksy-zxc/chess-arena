# ♞ Живая Арена: пиксельные шахматы

Пиксельные браузерные шахматы, в которых **поле живёт своей жизнью**. Под капотом настоящие шахматы со всеми правилами, а сверху длинное поле 8×14 и 12 скрытых клеток с семью событиями: лава, зеркало, заморозка, турбо, прокачка, подкрепление и портал.

🎮 **Играть:** https://asterisksy-zxc.github.io/chess-arena/

> Azyon Incubator 2026, второй тур: «Шахматы». Игра сделана с помощью ИИ (Claude Code).

## Своя фишка: скрытые клетки событий

### 🗺️ Длинное поле 8×14
Обычная армия, но между соперниками 10 пустых горизонталей. Пешки превращаются на 14-й горизонтали. Рокировка, взятие на проходе и превращение работают как в классике.

### 🕺 Невидимые клетки и диско-волна
В середине поля спрятано 12 **невидимых** клеток, в каждой партии в случайных местах. Фигура, наступившая на такую клетку, запускает **диско-волну**: от клетки по полу кольцами расходятся неоновые цвета, затем пол вспыхивает цветом события, и событие начинается.

| Цвет | Событие | Что происходит |
|---|---|---|
| 🟧 Оранжевый | Пол — это лава | Четверть пустых клеток на 3 хода превращается в лаву: по ней нельзя ходить и сквозь неё нельзя бить |
| 🟪 Розовый | Зеркало | Вся доска отражается слева направо: фланги меняются местами, рокировка пропадает |
| 🟦 Голубой | Заморозка | Три фигуры соперника (кроме короля) вмерзают в лёд на 2 его хода: ходить не могут, но клетки держат |
| 🟩 Зелёный | Турбо | Нашедший сразу ходит ещё раз. Если соперник под шахом — вместо этого прокачка |
| 🟨 Жёлтый | Прокачка | Фигура повышается: пешка → конь → слон → ладья → ферзь. Ферзь и король прокачивают соседа по армии |
| 🟥 Красный | Подкрепление | На своей половине поля из пола вырастают две новые пешки |
| 🟪 Фиолетовый | Портал | Фигура телепортируется в случайную свободную клетку на половине соперника (король в портал не пролезает) |

### ⚖️ Правила событий
- События складываются: во время лавы можно найти зеркало или заморозку. Вторая лава поверх первой превращается в прокачку.
- Использованная клетка исчезает, но поле не пустеет: как только клеток меньше девяти, где-то прячутся ещё три.
- Событие никогда не подставляет короля того, кто нашёл клетку: портал выбирает только безопасные клетки, а лёд никогда сам по себе не ставит мат или пат. Шах, мат и пат учитывают лаву и лёд.
- Всё случайное в событиях считается от зерна партии, поэтому один и тот же ход всегда даёт один и тот же результат.
- Список возможных ходов не зависит от скрытых клеток, поэтому их нельзя «вычислить» по подсказкам. Бот тоже не знает, где они.
- Есть режим **«Классика 8×8»**: чистые шахматы без событий.

### 🕹️ Аркадный стиль
Пиксельные спрайты фигур, нарисованные в коде (SVG из пиксельных карт), насыщенная неоновая палитра, пиксельные шрифты, табло вместо интерфейсных карточек, эффект CRT и чиптюн-звуки на WebAudio.

## Что есть в игре
- ✅ Все правила: рокировка, взятие на проходе, превращение пешки, шах, мат, пат, троекратное повторение, правило 50 ходов, недостаточный материал.
- ✅ Игра вдвоём на одном устройстве, индикатор хода, кнопка «Новая игра».
- ✅ Бот с тремя уровнями (альфа-бета поиск в Web Worker). Он понимает лаву, лёд и отражённую доску, но не знает, где спрятаны клетки.
- ✅ Подсветка доступных ходов, последнего хода и шаха; перетаскивание и клик.
- ✅ История ходов в русской нотации (Кр, Ф, Л, С, К), отмена хода, переворот доски.
- ✅ Таймер (5 / 10 / 15 минут).
- ✅ Адаптивная вёрстка под телефон, чиптюн-звуки.

## Запуск локально
Проект статический, сборка не нужна. Из-за ES-модулей нужен любой локальный сервер:

```bash
python -m http.server 8080
```

Затем откройте http://localhost:8080.

## Тесты движка
```bash
node tests/run.mjs
```
Perft на эталонных позициях (стартовая, Kiwipete и др.) подтверждает корректность генерации ходов, включая рокировку, взятие на проходе и превращения. Ещё есть сценарии для каждого из семи событий и 60 случайных партий на арене (около тысячи срабатываний).

## Структура
```
index.html        разметка и диалоги
css/style.css     оформление, анимации, адаптив
js/engine.js      правила, клетки событий, нотация, perft
js/ai.js          бот (альфа-бета + форсированные взятия)
js/ai-worker.js   запуск бота в отдельном потоке
js/main.js        интерфейс: доска, ввод, эффекты, таймер
js/sprites.js     пиксельные спрайты фигур и иконок
js/sound.js       чиптюн-звуки
tests/run.mjs     тесты движка
```
