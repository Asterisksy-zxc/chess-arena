# ♞ Живая Арена: пиксельные шахматы

Пиксельные браузерные шахматы, в которых **поле живёт своей жизнью**. Под капотом настоящие шахматы со всеми правилами, а сверху арена 10×10 с цветными клетками событий: метеориты, туман войны и ночь.

> Azyon Incubator 2026, второй тур: «Шахматы». Игра сделана с помощью ИИ (Claude Code).

## Своя фишка: клетки событий

### 🗺️ Поле 10×10
Обычная армия стоит по центру, по краям остаются открытые фланги. Пешки превращаются на 10-й горизонтали. Рокировка, взятие на проходе и превращение работают как в классике.

### 🟥🟦🟪 Клетки событий
На поле есть цветные клетки. Фигура, вставшая на такую клетку, заставляет её **вспыхнуть своим цветом** и запускает событие:

| Цвет | Событие | Что происходит |
|---|---|---|
| 🟥 Красная | Метеориты | На половину соперника летят 3 метеорита. Цели видны сразу, удар через 2 хода. Фигуры на целях уничтожаются, на их месте остаются кратеры, через которые нельзя ходить |
| 🟦 Синяя | Туман войны | Соперник ослеплён на 3 своих хода и видит только клетки рядом со своими фигурами. При игре вдвоём между ходами появляется экран «передайте устройство» |
| 🟪 Фиолетовая | Ночь | На 3 хода для всех: ладьи, слоны и ферзи ходят и бьют не дальше 3 клеток |

### ⚖️ Правила событий
- Одновременно идёт одно событие. Пока оно идёт, остальные клетки погашены.
- Клетки расставлены симметрично. Использованная клетка исчезает, а когда клеток становится мало, появляется новая симметричная пара.
- Метеориты не трогают королей. Шах, мат и пат учитывают ночь и кратеры.
- Результат события определяется зерном партии, поэтому бот просчитывает его так же, как игрок видит его на экране.
- Есть режим **«Классика 8×8»**: чистые шахматы без событий.

### 🕹️ Аркадный стиль
Пиксельные спрайты фигур, нарисованные в коде (SVG из пиксельных карт), палитра Sweetie 16, пиксельные шрифты, табло вместо интерфейсных карточек, эффект CRT и чиптюн-звуки на WebAudio.

## Что есть в игре
- ✅ Все правила: рокировка, взятие на проходе, превращение пешки, шах, мат, пат, троекратное повторение, правило 50 ходов, недостаточный материал.
- ✅ Игра вдвоём на одном устройстве, индикатор хода, кнопка «Новая игра».
- ✅ Бот с тремя уровнями (альфа-бета поиск в Web Worker). Он понимает события арены, сам использует клетки и уводит фигуры от метеоритов, а в тумане «теряется» и играет слабее.
- ✅ Подсветка доступных ходов, последнего хода и шаха; перетаскивание и клик.
- ✅ История ходов в русской нотации (Кр, Ф, Л, С, К), отмена хода, переворот доски.
- ✅ Таймер (5 / 10 / 15 минут).
- ✅ Адаптивная вёрстка под телефон, чиптюн-звуки.

## Запуск локально
Проект статический, сборка не нужна. Из-за ES-модулей нужен любой локальный сервер:

```bash
python -m http.server 8080
```

Затем откройте http://localhost:8080.

## Тесты движка
```bash
node tests/run.mjs
```
Perft на эталонных позициях (стартовая, Kiwipete и др.) подтверждает корректность генерации ходов, включая рокировку, взятие на проходе и превращения. Ещё есть сценарии для каждой клетки событий и 40 случайных партий на арене.

## Структура
```
index.html        разметка и диалоги
css/style.css     оформление, анимации, адаптив
js/engine.js      правила, клетки событий, нотация, perft
js/ai.js          бот (альфа-бета + форсированные взятия)
js/ai-worker.js   запуск бота в отдельном потоке
js/main.js        интерфейс: доска, ввод, эффекты, таймер
js/sprites.js     пиксельные спрайты фигур и иконок
js/sound.js       чиптюн-звуки
tests/run.mjs     тесты движка
```
